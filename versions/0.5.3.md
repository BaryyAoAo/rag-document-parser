# 0.5.3 — OCR 审核按文件分组

- 状态：已发布至 GitHub
- 日期：2026-10-21
- 目标：减少多页文档和历史任务在 OCR 审核列表中的重复展示。

## 新功能

- OCR 审核主列表按单次文件解析分组；同名文件的不同运行分别显示。
- 文件卡片展示文件名、工作台批次、涉及页码、待处理数和已完成数。
- 点击文件卡片展开审核页；页内继续保留原生结果、OCR 结果对照及逐页审核操作。
- 状态筛选先筛出符合条件的文件，再在展开内容中显示相应页面。

## 修复

- 原页面按页平铺，四页 PDF 会重复显示四次文件名和批次信息，历史任务增多时难以定位。

## 兼容性

- OCR 任务、决定、执行及定稿规则不变；仅调整 Vue 面板的展示方式。
- CLI、Python API、Web API 和 `ParsedDocument` Schema 不变。

## 验证

- Vue TypeScript 检查及生产构建通过。
- Python 自动测试通过；本地服务可加载新页面资源。

## 已知限制

- 当前只提供按状态筛选；暂不提供跨文件批量批准或批量应用决定。
