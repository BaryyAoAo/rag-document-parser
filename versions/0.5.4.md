# 0.5.4 — 按文件批量批准与执行 OCR

- 状态：已发布至 GitHub
- 日期：2026-10-21
- 目标：让多页文件的 OCR 批准和执行可以在文件卡片中一次完成，并保留逐页核对。

## 新功能

- 文件卡片展开后提供“批量批准 OCR”和“批量执行 OCR”，按钮显示当前符合条件的页面任务数。
- 批量批准仅处理该文件中尚未决定、允许执行 OCR 的任务；其他状态不重复操作。
- 批量执行由本地服务后台处理，最多同时执行 2 页；页面显示完成数及逐页失败原因。
- 批量执行失败的页面保留待执行状态，可检查原因后再次执行。

## 修复

- 多页文件过去需要反复逐页点击批准和执行，操作冗长且不易追踪整体进度。

## 兼容性

- OCR 结果仍需逐页对照并选择采用方式；本版不批量应用审核决定。
- 新增 OCR 批量批准、执行和进度接口；CLI、Python API 与 `ParsedDocument` Schema 不变。
- 批量执行进度保存在当前 Web 服务内存中；页面切换后可继续查看，服务重启后可从各页任务状态确认结果。

## 验证

- Python 自动测试覆盖批量批准、后台执行和状态完成。
- Vue TypeScript 检查及生产构建通过。

## 已知限制

- OCR 服务可能有调用限额；并发上限固定为 2 页，暂不提供面板调节。
