# 0.3.0 — 本地操作面板

- 状态：已发布至 GitHub
- 日期：2026-10-11
- 目标：在现有 CLI 之外提供单人使用的本地浏览器操作面板，保留原有解析产物和审核记录。

## 新功能

- 新增 Vue 3 + TypeScript 操作面板和本地 FastAPI 服务；`document-parser web` 启动后默认打开浏览器，只监听 `127.0.0.1`。
- 支持选择文件、文件夹上传，或输入本机文件和目录路径；可设置批次内部并行文件数。
- 批次与逐文件状态实时更新，展示完成比例、成功、待审核、失败和停止数量。任务状态持久化到 `web_jobs/`，重启后可查看历史。
- 可停止后续文件、重试失败文件，查看解析错误、运行目录、Block 摘要及 PDF 源文件。
- OCR 审核页支持记录常见决定、在线执行已批准的百度 OCR、应用决定；操作仍进入原有追加式审核记录。
- 批量解析 Python API 新增进度回调和取消事件，CLI 批量命令不受影响。

## 修复

- 排队中的任务被停止时，所有文件会标记为已停止，完成计数同步更新。
- Web 服务重启时将遗留的排队、运行和停止中任务标记为“运行中断”，避免误显示为正在处理。

## 兼容性

- `ParsedDocument` Schema 仍为 `1.0`；现有 `parse`、`batch` 及审核 CLI 用法不变。
- Web 依赖通过 `pip install -e ".[web]"` 单独安装；普通 CLI 安装无需 FastAPI。
- Vue 构建产物随 Python 包交付，使用面板无需安装 Node.js。
- Web 批次一次运行一个；每个批次内部继续按 `workers` 文件级并发。

## 验证

- 全量 28 项 Python 测试通过，覆盖本地目录、文件上传、结果持久化、OCR 审核和批次取消。
- Vue 生产构建通过；构建 Python wheel 并检查静态文件纳入包内。
- 本地 HTTP 服务启动及健康接口验证通过。

## 已知限制与下一步

- 复杂 OCR 合并或排除决定、结构审核目前使用 CLI。
- 非 PDF 文件目前显示解析后的 Block，不提供原文件版式预览。
- 文件上传上限为每个文件 200 MB；大批量上传和大型文档的真实数据性能仍需专项评测。
- 任务在服务重启后保留记录，不自动续跑中断的任务。
