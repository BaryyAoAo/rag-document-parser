# 版本记录

本目录按版本保存项目变化。每个版本文件都写明发布日期、目标、新功能、修复、兼容性、验证结果和已知限制。发布新版本时新增文件，不改写已经发布的历史记录；尚未推送或发布的版本标记为“待确认”；已推送版本标记为“已发布”。

| 版本 | 状态 | 说明 |
| --- | --- | --- |
| [0.1.0](0.1.0.md) | 已有基线 | 六格式解析、统一数据模型和审核流程 |
