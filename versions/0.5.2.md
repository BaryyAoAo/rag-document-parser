# 0.5.2 — 统一显示工作台批次与 OCR 文件运行编号

- 状态：已发布至 GitHub
- 日期：2026-10-20
- 目标：避免把一批文件的任务编号与单个文件的运行目录编号混为一谈。

## 新功能

- OCR 审核任务首行用醒目的深绿色“工作台批次”标签显示编号，与解析工作台的批次记录一致。
- 单文件的运行目录明确标为“文件运行”；保留跳转到对应解析结果的入口。

## 修复

- 原 OCR 页面把单文件运行目录写成“运行批次”，与工作台批次编号无法直接对照。
- 前端构建产物改用带内容哈希的文件名，刷新页面时避免继续使用同名旧脚本或样式。

## 兼容性

- OCR 列表接口新增 `web_job_id` 字段；没有对应 Web 批次的 CLI 运行返回空字符串。
- 批次记录、解析产物、CLI、Python API 和 `ParsedDocument` Schema 不变。

## 验证

- Web 测试验证 OCR 任务与所属工作台批次的关联。
- Vue TypeScript 检查及生产构建通过。

## 已知限制

- CLI 独立创建的 OCR 任务没有 Web 批次 ID，仍以文件运行目录识别。
