# 0.5.1 — OCR 审核批次定位与结果刷新

- 状态：已发布至 GitHub
- 日期：2026-10-14
- 目标：让同名文档的 OCR 审核与解析批次准确对应，并说明部分页面应用后的整份文档状态。

## 新功能

- OCR 任务显示所属运行批次，并提供“查看对应解析结果”入口。
- 解析结果显示本次运行 OCR 审核总数、已应用数、待应用数和已应用页码。
- 解析结果新增“刷新结果”按钮，重新读取有效 Block 与审核进度。
- 从 OCR 审核切回解析工作台时，重新读取当前文件详情。

## 修复

- 同名文档多次解析时，审核列表只显示文件名，容易把旧批次审核结果误认为新批次结果。
- 部分页面决定已应用时，成功提示误称“最终产物已更新”；现在说明还有多少项待应用。
- 原有批次列表刷新只更新任务状态，不会强制更新所选文件的详情及 Block 对照。

## 兼容性

- OCR 定稿规则不变：同一运行全部 OCR 审核任务应用后才生成整份文档的 OCR 有效版本；部分已应用页保存在审核产物中。
- CLI、Python API 和 `ParsedDocument` Schema 不变。详情接口新增 `ocr_progress` 字段。

## 验证

- Vue TypeScript 检查及生产构建通过。
- Python Web/OCR 测试覆盖审核进度和定稿状态。

## 已知限制

- 工作台“当前有效结果”只展示整份文档已定稿版本；部分已应用页的具体内容仍在 OCR 审核证据和运行产物中查看。
