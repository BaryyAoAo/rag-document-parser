# 0.6.0 — 文件历史、结果导出与 Office 预览

- 状态：已发布至 GitHub
- 日期：2026-10-21
- 目标：修复有效页脚文字误排除，按文件查找历史解析结果，方便用户导出当前有效版本并核对 Office 源内容。

## 修复

- PaddleOCR-VL 返回的文本型 `footer` 不再一律标记为检索噪声；页码和页脚图片仍按原规则处理。
- 为已有的四页公文生成独立的人工修订版本：恢复 OCR 已识别但被误排除的办公室文字，补入从原 PDF 第 4 页核对的“2025年12月29日印发”。保留 OCR 定稿版本及修订清单，不覆盖旧产物。

## 新功能

- 新增“解析历史”页面，按文件运行展示历史，支持搜索、状态筛选、跳转结果对照、打开文件或批次产出目录。
- 支持单文件下载当前有效 `ParsedDocument` JSON 或从其生成的 Markdown。
- 支持勾选多个可使用文件，导出到本机已存在的指定目录；导出文件名包含批次和文件序号，避免覆盖已有文件。
- DOCX、XLSX、PPTX 提供本地只读内容预览；XLSX 展示工作表及单元格，DOCX 展示段落和表格，PPTX 按幻灯片展示文字和表格。
- 新增 `GUI_GUIDE.md`，用文件夹示例说明面板解析、审核、结果对照、历史与导出的完整顺序。

## 兼容性

- CLI、Python 解析入口和 `ParsedDocument` Schema 不变。人工修订版是新的有效产物来源，位于 `manual_revision/finalized/`；仅在其依据的 OCR 或结构审核版仍为当前版本时优先读取，避免后续重新审核仍使用旧修订。
- Markdown 是派生导出格式，跳过明确标为 `excluded_from_retrieval` 的 Block；JSON 保留全部结构和审核标记。
- 历史页面显示本地 Web 工作台的批次文件记录。Office 预览是内容视图，暂不保证与 Office 排版完全一致，也不依赖外部文档服务。
- 自动 OCR 模式留待后续版本。

## 验证

- 自动测试覆盖页脚保留、人工修订版本不覆盖旧产物、历史列表、单文件及批量导出、Office 预览。
- Python 测试与 Vue TypeScript 生产构建通过；本机批次结果和服务接口已复核。
- 六格式文件夹按并行数 2 完成面板流程演练：6 个文件均完成初次解析，4 个可使用、2 个待审核、0 个失败；单文件 JSON/Markdown、批量 JSON 导出及三类 Office 内容预览均验证通过。未调用在线 OCR。
