# 0.4.1 — 修复 Block 对照滚动重置

- 状态：已发布至 GitHub
- 日期：2026-10-11
- 目标：让已打开的结构化 Block 对照在任务进度轮询期间保持稳定。

## 修复

- 文件详情的监听器原先每次计算都创建新数组；父页面刷新任务对象时，即使任务 ID、文件序号和运行目录未变，也会触发“切换文件”重置，清空 Block 列表并把滚动条带回顶部。
- 改为逐项监听这三个稳定值。只有真正切换文件或运行目录变化时才重置列表，正常任务轮询不再重载 Block。

## 兼容性

- 仅修复 Vue 页面行为；解析算法、`ParsedDocument` Schema、CLI 和 Python API 不变。

## 验证

- 用 Vue 响应式最小复现确认：父组件替换同内容文件对象时，旧监听器触发 1 次，新监听器触发 0 次。
- Vue TypeScript 检查和生产构建通过；全量 Python 测试保持通过。

## 已知限制

- 浏览器界面的滚动手感仍建议用真实长文档人工确认；当前自动化浏览器连接不可用。
