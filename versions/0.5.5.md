# 0.5.5 — OCR 定稿状态同步

- 状态：已发布至 GitHub
- 日期：2026-10-21
- 目标：让工作台“文件与结果”反映 OCR 审核后的当前有效产物。

## 修复

- 批次记录保存的是解析完成时的快照。OCR 全部应用并定稿后，工作台此前仍显示“待审核”和基础版本 Block 数量；现读取已完成的 OCR 或结构审核产物，显示当前文件状态和 Block 数量。
- OCR 定稿版本只有质量提示、没有错误和待处理的人工审核项时，文件显示“可使用”，同时保留质量提示供检查。
- 当前选中文件的有效产物发生变化时，文件详情自动刷新。

## 界面

- 文件名旁显示“OCR 已定稿”或“结构审核版”标签，便于识别当前有效版本。
- OCR 详情说明剩余质量提示与人工审核项的区别。

## 兼容性

- 原始批次 JSON、`batch_report.json` 和基础解析产物保持解析当时的记录；工作台状态由 API 读取有效版本时计算。
- CLI、Python API 与 `ParsedDocument` Schema 不变。

## 验证

- 自动测试覆盖 OCR 定稿后列表、详情、计数和 Block 数量同步，未完成的人工审核项仍显示“待审核”，服务重启后状态可恢复。
- Python 自动测试与 Vue TypeScript 生产构建通过。
