# 0.1.0 — 首个可复用解析流水线

- 状态：已有基线
- 日期：2026-10-10 前已存在；原始提交未单独标注发布日期
- 对应基线提交：`0fe6bda`（初始版本），`d2a3f21`（PDF 回归测试跨平台修复）

## 主要功能

- 将 PDF、DOCX、XLSX、HTML、Markdown、PPTX 统一转换为 `ParsedDocument` 和 Block。
- 保存原始解析摘要、清洗、修复、评测与人工审核等阶段产物。
- 按文件格式路由解析器；PDF 支持基础阅读顺序、表格排除和跨页修复。
- 提供 OCR 决策、远程 PaddleOCR-VL 可选调用及人工审核记录。
- 提供单文件和目录批量 CLI、Python API。

## 已知限制

- 目录批量解析逐文件串行执行。
- 运行目录采用秒级时间和文件名，短时间内同名文件可能冲突。
- 批次报告固定写入 `batch_report.json`，后续批次会覆盖先前报告。
- 复杂 PDF 版式和 XLSX 多个独立表格仍需改进。

## 验证

- 六格式回归样例、PDF Block 摘要、OCR 策略、结构审核与架构边界测试。
